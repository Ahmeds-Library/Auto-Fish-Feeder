# Legacy Prototype Code

This folder contains the original prototype static web UI and Arduino firmware.
It is kept only for historical reference.
Do not deploy or flash this code for the upgraded multi-device system.
The active web dashboard is in `/web`.
The active firmware is in `/firmware/esp8266-fish-feeder`.

Contents:
- `web-interface/` — original single-page static Firebase UI that used global prototype paths.
- `firmware-code/` — original Arduino sketch retained for historical comparison only.
